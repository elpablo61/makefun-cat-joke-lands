One joke about cats, one line, under 200 characters — nothing else.

The program (`main.ts`, Node 22) writes the joke to `/output/entry.txt`
(honouring `MAKEFUN_OUTPUT_DIR` when set) for the make.fun judge.

## Run

```sh
node main.ts
cat /output/entry.txt
```
